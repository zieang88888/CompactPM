# Data

CompactPM uses the public PowerMamba benchmark data for the GridSet-22
source-reference replication.

## PowerMamba dataset

Original public record:

https://zenodo.org/records/14451473

https://doi.org/10.5281/zenodo.14451473

`GridSet_no_pred.csv`
