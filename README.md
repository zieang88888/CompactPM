# CompactPM — Dataset Reference

This repository hosts **dataset references only** for the manuscript:

> **When Is Extra Recurrent Mixing Worth Its Cost? A Controlled Study for
> Multivariate Energy Forecasting**
> *(submitted to Engineering Applications of Artificial Intelligence, under review)*

During review, no model code or experiment results are published here.
They will be released together with the camera-ready version after acceptance.
